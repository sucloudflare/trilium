# TriliumNext Workspace

## Quickstart

1. Instalar dependências: `pnpm install`
2. Rodar servidor dev: `pnpm dev -F @triliumnext/server`
3. Rodar web: `pnpm dev -F @triliumnext/website`
4. Rodar apps: `pnpm dev -F @triliumnext/edit-docs`
5. Rodar CKEditor build: `pnpm build -F @triliumnext/ckeditor5`
